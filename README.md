# Lightbox Viewer 🖼️

A gallery-based project built as part of the freeCodeCamp curriculum. It allows users to view images in a lightbox.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ✨ Features
- Image gallery
- Lightbox image viewing

- Working with events
